## GaplessPlayer 1.0.0

给网易云音乐 PC 版做的**真无缝**播放引擎。把「下一首」提前排到「这一首」的最后一个采样上，切歌间隙从数百毫秒压到 **0**。

首个公开发布。

### 它能做什么

- **真无缝**：自然播完 → 下一首间隙 **0 ms**，采样级接缝，不是淡入淡出
- **提前预载**：当前歌还在响，下一首已经下完并解码好
- **开机预下**：记住上次播的那首，开机先把「马上就要播的这首」下好
- **两条路径自动切换**：能预载就走缓冲（可无缝），不能就边下边播（~0.5 s 出声）
- **不白耗流量**：随机播放押不中就自动关掉预载

### 效果

| 场景 | 未启用 | GaplessPlayer 1.0.0 |
| --- | --- | --- |
| 自然播完 → 下一首 | 卡 150~500 ms | **0 ms**（采样级接缝） |
| 点「下一首」 | 立刻 | 立刻 |
| 歌单第一首 / 预载未命中 | 等下载 + 解码 2~7 s | ~0.5 s（边下边播） |
| 开机第一首 | 等下载 | 开机就预下（记住上次那首） |

### 安装

1. 装好 [BetterNCM](https://github.com/std-microblock/BetterNCM)（本插件在 **网易云 2.10.13** 上开发、实测）。
2. 把下面的 `gapless-player-1.0.0.plugin` 放进 `C:\betterncm\plugins\`。
3. 重启网易云音乐。

建议同时启用 [LibEAPIRequest](https://github.com/BetterNCM/LibEAPIRequest)。不装也能播，但预载与无缝预约会关闭，退化成一首一首的流式播放。

### 已知限制

- **随机播放不预载**：切歌前不知道下一首是谁，实测 16 次预载 0 命中、白下 1076 MB。插件会自适应关掉预载。
- 只在网易云 **2.10.x** 验证过；依赖 `channel.call` / `legacyNativeCmder` 这些内部接口，客户端一升级就可能失效。
- 控制台逃生开关：`window.__gpSeamless` / `__gpStream` / `__gpNativeAll` / `__gpLogVerbose`。
